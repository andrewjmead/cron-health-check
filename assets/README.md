# Assets

WordPress.org plugin directory assets (not shipped in the plugin zip; uploaded to the `assets/` SVN directory).

Icon filenames per https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/#plugin-icons:

- `icon.svg` – vector icon
- `icon-128x128.png` – required PNG fallback
- `icon-256x256.png` – high-DPI fallback

`icon-concepts/` holds candidate designs (`preview.html` shows them side by side at 256/128/64/32px).
The current icon is `02-pulse`.
